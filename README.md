# Documentation de l’architecture d’affaires de la PDM

Ce dépôt contient une structure de documentation Markdown destinée à un site Zensical.

## Contenu

- `mkdocs.yml` : Configuration du site documentaire.
- `docs/index.md` : Page d’accueil du site.
- `docs/00-instructions/agent-architecture-affaires-pdm.md` : Prompt à fournir à un agent pour documenter l’architecture d’affaires de la PDM selon TOGAF.
- `docs/01-architecture-affaires/index.md` : Page d’entrée de la section Architecture d’affaires.
- `docs/01-architecture-affaires/gabarit-section.md` : Gabarit normalisé pour les sections de documentation.
- `docs/01-architecture-affaires/structure-livrables.md` : Structure cible des livrables à produire.

## Usage

Utiliser le prompt contenu dans `docs/00-instructions/agent-architecture-affaires-pdm.md` pour produire ou compléter les sections d’architecture d’affaires.

Les contenus doivent être rédigés en français du Québec, selon un style formel, clair et directement réutilisable dans un référentiel d’architecture.
